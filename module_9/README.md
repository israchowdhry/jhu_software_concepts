Approach: 

This module applies text clustering techniques to Grad Cafe program data in order to group similar program names into broader academic categories. The goal of the script is to reduce the large number of unique program name entries into a more manageable set of clustered program groups for downstream analysis. The script kmeans.py loads the cleaned JSON dataset cleaned_gradcafe.json, verifies that the required program_name and university columns are present, and then creates standardized Program and University columns for use throughout the clustering workflow. The preprocessing steps of removing rows where program values were “None” and separating program and university information were already completed in Module 8, so that cleaning did not need to be repeated here. The script also prints the total number of entries and the number of unique program input names so the size of the dataset can be examined before clustering begins.

After loading the dataset, the script applies scikit-learn’s TfidfVectorizer to the Program column in order to convert each program name into a numerical TF-IDF representation. This allows the text-based program names to be analyzed mathematically based on the relative importance of words across the full collection of program titles. Because the TF-IDF feature matrix is high dimensional, the script then applies Principal Component Analysis (PCA) in two different ways. A higher-dimensional PCA representation with 50 components is used for clustering so that more of the original text information is preserved, while a separate 2-component PCA representation is used only for visualization so the cluster plot can still be displayed in two dimensions. This separation improves the quality of the clustering while still producing a readable plot.

The script first performs an initial K-Means clustering with 50 clusters, a maximum of 100 iterations, and an n_init value of 5. The results of this initial clustering are visualized and saved as initial_cluster.png, using axis labels that match the assignment example. The script also saves a preview of the first 100 rows of the clustered dataframe as clustered_dataFrame.png, showing the program name, university, and assigned cluster. This preview helps illustrate how similar program names are being grouped together within the clustering process. The elbow method is then applied by fitting K-Means models for values of k from 1 through 100 and recording the inertia for each model. These inertia values are plotted and saved as elbow.png so the approximate optimal number of clusters can be examined visually.

Following the elbow analysis, the script performs a final K-Means clustering using k = 85 clusters, consistent with the assignment guidance. The resulting cluster labels are assigned back to the dataframe, and the complete clustered dataset is saved as grad_cafe_clustered.csv for further inspection and analysis. The script then identifies a Philosophy-related cluster and a Computer Science-related cluster by finding the most common cluster number associated with program names containing the keywords “philosophy” and “computer science.” For each of these clusters, the script creates a GRE score distribution plot using the gre_score and gre_v_score columns from the dataset. These box plots are saved as philosophy.png and computer_science.png and show the distribution of GRE and GRE Verbal scores within each selected cluster, making it easier to compare score ranges, medians, and outliers across these grouped program areas.

To run the script, place kmeans.py and cleaned_gradcafe.json in the module_9 folder and execute the script using Python 3.10 or later. Running the script will generate all required visualizations and the clustered CSV output in the same folder.
