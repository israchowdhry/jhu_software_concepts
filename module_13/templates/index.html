Grad School Cafe Admissions Predictor

Home Will You Get In?
This website includes a fine-tuned transformer model that predicts whether an applicant may be accepted or rejected using self-reported Grad Cafe data.

What this page does

This project combines text fields such as program name and comments with structured fields such as GPA, GRE, degree type, and citizenship category to generate an admissions prediction.

Try the prediction page

Go to the “Will You Get In?” page to enter applicant information and receive a model-generated prediction and probability score.

Disclaimer

This is a course project model trained on scraped, self-reported data. It is not a real admissions tool and should not be treated as a real admissions decision.
